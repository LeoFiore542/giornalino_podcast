# Giornalino

Ogni numero è una sottocartella, es. `vol-01/` con:

- `meta.json` (obbligatorio)
- `issue.pdf`
- `cover.jpg` (opzionale)

Esempio meta.json:

```json
{
  "volume": 1,
  "title": "Titolo",
  "description": "...",
  "date": "2026-01-15",
  "cover_class": "cover-spring",
  "file": "issue.pdf",
  "cover": "cover.jpg"
}
```
